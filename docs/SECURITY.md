# 凭据、费用与恢复

## 凭据与公开材料

使用受支持的环境变量或 DPAPI 引用，不把密钥值写入 manifest、源码、报告或 issue。海外凭据必须显式包装 `provider: "tripo-overseas"`、`region: "global"` 和安全引用；不能以中国站凭据探测海外主机。适配器不自动切地区或厂商。

签名 URL、上传 token、Authorization、原始响应体、账号余额、私人素材和财务账不应进入公开仓库或错误报告。报告问题时提供软件版本、动作、脱敏错误类别和可公开的最小复现，不粘贴真实凭据、任务或账本。SHA 用于完整性核对，不能证明批准者身份或素材权利。

## 费用授权

收费前需要绑定具体输入、规范请求 SHA、唯一账本、额度与次数的真实授权。可用余额、只读查询成功、已有订阅或历史授权不能替代新请求授权。各提供商和地区的批准、请求身份与财务账分别维护，不能复制空账、换路径或回滚旧快照来重置消费。

海外金额最多两位小数。当前公开无贴图单图/多视图基础估价为 20 credits，只作本地最低预约及计划依据，不能保证服务端扣费上限。终态 `credits_consumed` 缺失时保留预约，不能假定零费用或固定费用；成功但视觉失败也可能收费。

## 未知提交与下载

accepted task 不再次 POST。上传失败、提交未知、取消或 I/O 异常可能保留预约；超时不证明服务端未创建任务，也不授权重新提交。先保留原请求、财务状态和脱敏受理证据，再按该提供商实际支持的恢复合同处理；本地取消不等于云端取消或退款。

海外当前无 bind、resume、batch 或账本迁移；已知任务可以显式 query，下载必须限制 `max_download_bytes`，完整 GLB 校验及持久文件验证成功后才认定交付。失败保留定位，不自动重试、跨区 fallback 或复用中国站检查点。中国站具备的特定恢复合同也需要原账和对应证据，不能据此承诺任意故障可恢复。
