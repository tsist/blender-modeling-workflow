# 验证范围

本发行只做基础检查，没有生成新模型，也没有进行建模或Blender安装测试。未运行的路径不会因打包、注册信息或模拟响应而提升为生产验收。

可复跑的检查无需账号、密钥、网络或Blender：

```powershell
python -B tests/provider_smoke.py
python -B tests/repository_smoke.py
python -B scripts/build_release.py --destination '<新的输出目录>'
```

`provider_smoke.py` 使用临时小PNG/GLB容器和fake transport验证请求参数、地区与账格式隔离、费用小数、未知结果保留/不重发、查询脱敏及下载字节/SHA。合成容器不是建模产物或模型质量测试。`repository_smoke.py` 验证发现/Schema、作业合同和失败终态、技能安装保护、内部链接、发行成员及解包消费者。构建白名单拒绝产品额外文件，不把凭据、运行记录、素材或模型装入ZIP。

海外基本适配在发行前做过一次真实只读余额GET，证明对应账户在当时可鉴权和连通；不公布账户余额或返回原文。本仓CI不会访问真实服务。没有实际海外生成、扣费、模型下载或Blender链路证据。

中国站历史已有H3.1公开生成→查询→下载→本地导入与独立重开的有限真实案例，部分其他操作也有具名服务调用。该历史事实不证明本轮新源码解压后的完整建模链已重验。Meshy只有已有任务的只读适配及离线验证；第二厂商生成、全部模型版本、任意骨骼/动画、通用语义分件、重拓扑和自动修复不在已验承诺内。

CLI发行适配保留原合同、财务与文件保护，并将公共运行时收束为建模所需模块。源码指纹是本仓当前全部CLI/addon Python字节的聚合；它与母项目指纹不同，不允许直接重放原项目付费请求。本机基础检查使用Windows与Python3.13.13，CI矩阵以实际运行结果为准；不承诺macOS/Linux文件锁、断电一致性、非合作写者原子CAS、新机部署或任意Blender版本。
