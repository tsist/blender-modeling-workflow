# 部件分流、局修与材质 UV 交接

外部生成件拿进 Blender 后，先把整模按部件拆开看，决定哪些直接沿用、哪些局部整理重拓扑、哪些交给硬表面重建，再按清晰清单交接给 UV 和材质部门。

## 按部件分流：沿用、重拓扑还是重建控制笼

每个部件按后续用途和变形要求选路，同一件作品里不同部件灵活混用：

| 部件特征与用途 | 推荐做法 | 下一步动作 |
|---|---|---|
| 有机雕塑主体、复杂雕花、静态配饰，轮廓与细节已经到位 | **直接沿用生成网格** | 保留原件，另存制作副本做轻度清理与 UV/材质交接 |
| 面数过密、局部有布尔碎面或需要轻量改形的部件 | **局部整理与重拓扑** | 在制作副本优先加可编辑修改器，或经 `model prepare` 执行平面融并和重拓扑回投影 |
| 规则硬表面、精确倒角、开孔、装配转轴、要反复改型的壳体或武器 | **转交硬表面重建控制笼** | 把生成候选留作尺寸和轮廓参考，交 [blender-hard-surface-modeling](https://github.com/tsist/blender-hard-surface-workflow/blob/main/skills/blender-hard-surface-modeling/SKILL.md) 从稀疏四边面控制笼重做 |

### 局部减面与重拓扑操作

处理生成白模和布尔碎面时，优先保留修改前候选，使用公共 CLI `model prepare` 或明确目标的可编辑修改器：

- **平面融并**：对过密平直面用 `modifier.add` 加 `DECIMATE`（`DISSOLVE`）或 `mesh.dissolve_limited`，压低冗余面数同时保住硬轮廓。
- **自动四边重拓扑**：用 `mesh.retopology`（`QUADRIFLOW_SHRINKWRAP_V1`）执行带体素回退与 Shrinkwrap 回投影的重拓扑。该步骤会重建网格并丢弃旧 UV、顶点组与形态键，完成后紧接着安排重展 UV 或按源模投射烘焙。
- **控制修整范围**：有明确缺陷证据再动几何；需要大范围重塑主体轮廓时，回到参考与生成方案重新出候选，把精力留给主效果。

## 分件、补全与独立素体配合

处理角色或多部件道具时，把对象数、连通岛、语义部件和拓扑质量分开看，逐件孤立检查手袖、颈领、内外衣层、头皮与头发、鞋腿的遮挡和接合。

- **原生分件与后处理分件**：云端生成的原生分件（`h31_parts_multiview`）和后处理分件（`segment_v2`）属于不同流程。检查时把每件单独孤立出来，看隐藏躯干、内层衣服和重复配饰是否粘连，并记录 UV 与接合缺口。
- **全件补全衔接**：需要调用云端全件补全（`complete_all_v1`）时，以同一账本内已成功结算的 `segment_v2` 任务作父任务。补全会封闭边界，仍需逐件复查手袖和衣层有没有粘连，以及封帽后的 UV 与材质缺项。
- **独立素体参考与衣物配合**：宽松外套、披风或长裙会把四肢粘连成实心块。需要独立躯干时，准备同身份、A 姿或 T 姿的贴身素体正背参考单出一版素体候选。先锁住素体头身比、五指和四肢连续度并重开定尺，再同视角比对衣物内外表面与净空。查看穿透时把完整素体图、隐藏素体后的衣物隔离图和实际命中点一起看，避开跨开口误读远表面。
- **沿非共面袖口切分与可逆形态键**：切分已有表面前先整圈查看袖缘，确认为平面再用平面切割，保留双侧独立网格与源面映射，切后逐源面核对面积守恒、闭合环、法线、锐边与 UV 属性。做局部位置或厚度微调时，优先建可逆形态键，写清目标位置是绝对世界坐标还是增量；绝对位置已含旧适配时启用新键并将旧键归零，同时检查感兴趣区域之外的求值点与受影响三角法向，确保没有翻面或轮廓拉坏。
- **灰模局部明暗诊断**：眉眼、颈领或腕掌出现块状暗斑时，先保持原几何，换多视角、关闭投影阴影或临时分色排查，确认属于几何折痕还是光照视角问题后再决定是否开局部 ROI 调整。

## 硬表面白模局部曲面返修要点

对嵌板、提手、底脚和融合根部做白模返修时，按下面顺序逐项把关：

1. **先做隔离诊断**：用中灰无纹理材质、固定相机和条形灯，把主体、壳体和嵌板分开渲图，区分控制网格、近共面遮挡、法线和布尔交界。
2. **给宽大嵌板留足内部控制点**：按边界建立规则内部网格，抽查中心与行列实际坐标，确认参数映射平滑无折叠后再做边缘倒角。
3. **贴合采样取稳定源面**：采样贴合时对着未开槽的干净源曲面或已核对的解析截面求值，保留失败样本方便对照。
4. **厚度、滚边与接触分开构造**：曲面稳定后再加厚度和倒角，留出合理间隙避开近共面闪烁，并实测声明接触区的最近距离与相交情况。
5. **融合过渡与底脚先查包络**：提手和底脚与主体融合后，回头核对落地高度、尾壳包络、负空间和完整轮廓；出现台阶或连接变弱就退回最近安全候选。

## 交给 UV 与材质部门

进入 [blender-uv](https://github.com/tsist/blender-uv-workflow/blob/main/skills/blender-uv/SKILL.md) 和 [blender-material-authoring](https://github.com/tsist/blender-material-workflow/blob/main/skills/blender-material-authoring/SKILL.md) 前，把候选网格、贴图和映射现状交清楚：

1. **留住原文件与编码**：完整保留原始 GLB、提取图像原编码、来源索引和 SHA256，所有精修在新制作副本上进行，原材质留着对照。
2. **逐条核对贴图与通道**：从实际节点连线核实 UV 层、材质槽、打包图像与色彩空间。把 `Base Color` 设为 `sRGB`，法线、粗糙度、金属度以及 ORM 拆包单通道设为 `Non-Color`，确认法线走 Normal Map 节点并核对 G/B 分量实际去向。
3. **保护零用户数据块与共享引用**：编辑共享 Mesh 或材质槽前先单用户化。源工程要求保留孤立材质或世界数据块时，通过展示集合引用保住它们，并在保存冷重开后逐项复核。
4. **选对 UV 与材质修改工具**：
   - 需要重新展 UV 或补光照图 UV2 时，交给 `blender-uv` 选用最小拉伸展开（`MINIMUM_STRETCH`）、角度或锐边加缝（`MARK_BY_ANGLE` / `MARK_FROM_SHARP`）和辅助 `lightmap` 层（`UVMap_Lightmap`），保留原渲染活动层。
   - 需要调整已有材质节点时，按实际合同确认是否属于 Material Workflow 受管结构；对非受管导入节点做有限调参时，先查当前 `node.prepare` 合同，按网格规模留足异步作业超时预算。
5. **跨拓扑迁移贴图与遮罩复核**：拓扑变动后，用有界同源面投射迁移原贴图，按距离、法线和部位筛选，把无法映射的区域标成待制单色材质并记录覆盖率。给局部区域加遮罩后，打开背面、侧面和原尺寸近景复查，结合最近可见面筛选消除投影串色。
6. **交付清单**：向材质与 UV 部门交出最终 `.blend` 路径与 SHA256、对象与材质槽清单、UV 层与贴图映射状态、目标外观说明、同条件预览机位及待补缺口。
