# 生成与候选比较

输入为冻结参考、明确预算和实际支持操作。读当前 `modeling describe --operation run --schema`，用 Schema 构造 UTF-8 请求，不猜 API 字段。submit、query、download 是不同动作；受理后沿原 task 查询下载，已有有效产物从[Blender 交接](blender-handoff.md)进入。

保留参考 SHA、地区/提供商、模型版本与请求参数、task_id、费用回执、原始文件/SHA 和父候选关系。提交未知立即转[恢复](recovery.md)，停止同一意图的收费重发。查询网络失败与远程 failed 分开；远端成功后仍要持久下载、校验并查看。中国站、海外与 Meshy 的动作范围不同，不能把本指南当作开放全部收费后处理；本次发行验证未新增模型生成或 Blender 制作。

已批准候选数/轮数内自主比较。共用相机方向、构图、照明、引擎和色彩管理，以正背、必要侧面、四分之三及脸/接合局部观察身份、比例、衣层、遮挡与表面。视角按缺陷选，不固定数量，不以正面美图、面数或 API 完成替代质量判断。更换照明后检查实际解码像素确实变化。

先判断主体是否能继续制作，再安排贴图、分件等收费后处理。记录可用用途、主要差距、局部可修项及需重新生成项。几何与带材质预览分别观察：贴图可能强化身份，也可能掩盖几何缺失。前后结果的接口、模型、seed 或输入不同，单例改善不能归因为某一个因素普遍有效。

输出比较与推荐，在授权内继续局部整理，最终选用状态单列。达到预算/轮数上限、主体偏差需大范围重塑或接口缺能力时，保留最佳候选与失败证据，形成下一具体路线；不静默降质量、无限本地拟合、换厂商或扩大费用。后处理读[分件与补全](parts-and-completion.md)，多项请求读[有界批量](bounded-batches.md)。
