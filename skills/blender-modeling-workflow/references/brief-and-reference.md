# 设定与参考准备

从文字或现有参考进入。已有确认图片不必重新出图；缺少背面、配饰朝向或关键遮挡才补视图。优先合法自有或新创作参考；代理先准备新输入候选，再按既定约定由用户确认。已有授权内的修订直接推进，不重复确认旧参考。图像创作有相应技能/工具时协作；本技能负责三维输入可用性。

用简短身份清单约束脸、发型、头身比例、服装层次、左右不对称配饰、手足姿态及前后关系。多视图围绕同一身份和静置姿态，检查轮廓、颜色、侧别、开口与遮挡。视图数量、裁切和格式由实际 API 与缺口决定，不固定四张；仅有正面时新增背面是设计提案，不能冒充参考真值。

独立身体参考沿用角色身份与比例，让被宽松衣物遮挡的躯干、四肢连续可读；可用不透明少褶皱基础贴身服表达形体。它是新的输入，不证明完整裸体解剖，也不替换原服装设定。先锁定正面，再以正面及已知背面身份准备背面；核对头脚高度、肩腰髋宽度、A 姿势、手指和脚朝向。剩余二维差异单列，合身与可绑定须经三维结果验证。

真正提交的各视图独立保存，记录原图、修订图、标签、SHA 与认可范围。拼图用于审阅；API 需分图时不把拼图当单视图。使用 front/back 等具名视图，不按数组位置猜顺序。

身份矛盾或关键缺图先修参考，不靠增加候选数量掩盖。新私密素材外发范围未覆盖时补齐该范围。进入[提供商与预算](provider-and-budget.md)；恢复时核对冻结文件/SHA，修改后的文件不能挂旧 SHA。

需要证明方法泛化时，另保留未参与开发的独立留出样例，冻结输入、方法和判据。样例一旦用于改进方法，就不能继续称新方法未见输入；本地新上下文交接与真实收费全流程验收分别设计。
